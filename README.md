- **Nome do Aplicativo**: CineUp
- **Descrição**: O Aplicativo CineUp é um catalogo de filmes, que apresenta informações como Nome, Categoria, Ano de Lançamento. É possível adicionar o filme aos favoritos e visualizar os detalhes do Filme. Essa aplicação foi desenvolvida para a matéria de PDM, afim de explorar o nosso aprendizado durante as aulas e exercicios aplicados em sala.

### Instruções de Execução

1. Instalar Dependências

   ```bash
   npm install
   ```

2. Iniciar Aplicativo

   ```bash
   npx expo start
   ```
3. Execução
- Android Studio:
  - Entre no aplicativo do Android Studio, inicie o aplicativo e aperte (A) no terminal caso a aplicação não inicialize
- Celular (Expo Go):
  - Abra o Aplicativo do Expo Go no seu celular, **seu celular e seu computador devem estar conectados na mesma rede**, escaneie o QR Code que vai ser disponibilizado no terminal e sua aplicação vai estar rodando perfeitamente
